# 천안시 AI 행정(행사·회의 등) 문서 작성 꾸러미

정보를 한 번 넣으면 **천안시 원본 양식 그대로** 행사·회의 문서 6종(계획서·요지·사회자 시나리오·보도자료·순서진행 PPT·결과보고)을 만들어 주는 프로그램입니다. 만든 문서는 내려받기 전에 문서 모양 그대로 미리 볼 수 있습니다.

| 행사 전 | 행사 후 |
|---|---|
| ① 개최 계획(안) · ② 보고요지 · ③ 진행 시나리오 · ④ 보도자료(미리 배포용) · ⑤ 진행 PPT | ⑥ 결과보고 — 개최계획서와 회의록 파일만 넣으면 건의사항·시장님 총평·붙임 회의록까지 정리 |

- 결재란·글꼴·표 모양·로고 등 원본 서식은 그대로 두고 글자와 표의 행 수만 바꿉니다.
- 일시·요일·종료 시각·예산 합계(한글 금액)·참석 인원은 자동으로 계산하고, 문서끼리 값이 맞는지 검사합니다.
- **내 컴퓨터에서만 돌아갑니다.** 입력한 행사 정보와 만든 문서는 인터넷 서버로 보내지 않습니다.

## 내 컴퓨터에 설치해서 쓰기

👉 **[설치파일 바로 내려받기 (kkureomi-setup.zip)](https://github.com/qw125506-byte/kkureomi/releases/latest/download/kkureomi-setup.zip)** · [배포판 목록](../../releases/latest)

## 설치하고 켜기 (Windows 10·11)

1. 위에서 받은 `kkureomi-setup.zip`을 오른쪽 클릭 → **압축 풀기**
2. 풀린 `문서꾸러미` 폴더의 **`문서꾸러미 실행.bat`** 을 두 번 누릅니다.
   - 「Windows의 PC 보호」 창이 뜨면 **추가 정보 → 실행**
   - 처음 한 번은 필요한 프로그램(Python 등)을 자동으로 설치합니다(인터넷 필요, 몇 분).
3. 잠시 뒤 브라우저에 문서꾸러미 화면(`http://localhost:8010`)이 열립니다.
4. 다 쓰면 검은 창을 닫으면 꺼집니다. 다음부터는 2번만 하면 됩니다.

> Python 자동 설치가 안 되면 <https://www.python.org/downloads/> 에서 Python 3.12를 설치하세요.
> 설치 첫 화면의 **Add python.exe to PATH** 를 꼭 체크한 뒤 2번을 다시 하면 됩니다.

## 쓰는 법

- 처음에는 **「예시 불러오기」** 를 눌러 보세요. 가상 행사(청년 창업가 간담회)로 모든 칸이 채워집니다.
- **행사 전**: 행사 정보·식순·참석자를 넣고 **「문서 5종 만들기」** → 파란 「미리보기」, 주황 「내려받기」
- **행사 후**: 개최계획서와 회의록 파일을 「행사 후 결과보고」 칸에 끌어다 놓고 **「⑥ 결과보고 만들기」**
  (「예시 계획서·회의록 넣기」로 먼저 체험해 볼 수 있습니다.)
- 비어 있는 칸은 `ㅇㅇ`·`[확인 필요]`로 표시됩니다. 내려받은 문서에서 꼭 확인해 고쳐 주세요.

## 알아 둘 점

- 한글(HWPX) 문서는 한컴오피스 한글 2014 이상, PPT는 PowerPoint에서 엽니다.
- 보도자료·결과보고 문장은 프로그램이 자동으로 쓴 **초안**입니다. 사실관계를 꼭 확인하세요.
- 양식 속 원래 사람 이름·전화번호는 배포본에서 `○○○`·`041-000-0000`으로 지웠습니다. 만드는 문서에는 입력한 값이 들어갑니다.
- 예시 행사의 기관·사람 이름은 모두 지어낸 것입니다.
